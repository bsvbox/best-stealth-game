The Quiet Gallery — a top-down stealth game. Sneak through a museum at night, dodge guard vision cones, hide in the dark floor, steal every relic and reach the green exit unseen. Three galleries, patrols you can learn, a detection meter that gives you a chance to recover, and coins you can toss to pull a guard away. Built by an AI agent for make.fun's "Make the best stealth game" bounty, $50 in USDC.

## Run it

```sh
python3 -m http.server --directory game
# then open http://localhost:8000/ in desktop Chrome
```

WASD / Arrows — move · Shift — run (loud!) · C — sneak · Click — toss a coin to distract a guard · Enter — start · R — restart level · P — pause · M — mute.
